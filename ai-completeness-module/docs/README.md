# Документация самостоятельного пакета комплектности

Это локальный индекс. Описание интегрированной вкладки основного прототипа находится в [спецификации проверки](../../docs/07-check-workspace-target.md); документы пакета не переопределяют её компоновку, действия или итоговые статусы.

## Как выбрать документ

| Задача | Документ-владелец |
|---|---|
| Запуск, состав, ограничения переноса | [README пакета](../README.md), [манифест](../module_manifest.json) |
| Связь изменённого файла с документацией | [Реестр](component_registry.json), [workflow](ui_docs_sync_workflow.md) |
| Размещение и изменение состава файлов | [Карта структуры](project_structure_map.md) |
| Статусы и цветовое кодирование пакета | [Статусы](design_system_statuses.md) |
| Самостоятельные вкладки и разделитель | [AICompletenessTab](../src/components/AICompletenessTab/ai_completeness_tab.md) |
| Иерархия, состояния, данные, поиск | [FileTree](../src/components/FileTree/file_tree_and_pipelines.md) |
| Данные и режимы правой области | [MetadataPanel](../src/components/MetadataPanel/metadata_panel.md) |
| Черновик фильтров и применение | [Filtering](../src/components/Filtering/filtering.md) |
| Демонстрационный чат модуля | [AISidebarDrawer](../src/components/AISidebarDrawer/ai_sidebar_drawer.md) |

ThreadedRemarks не монтируется и не является частью текущего пользовательского пути. Его остаточные CSS и mock-данные не требуют чтения при работе над прототипом. Комментарии АНР/РД и переносимый чат основного проекта — другие реализации.

## Правило чтения и проверки

Начать с документа изменяемого компонента; условные потребители определяются реестром. Не читать все компоненты или материалы встреч заранее. Из корня пакета команда `node scripts/docs-sync-check.js <changed-file>` показывает маршрут, но не проверяет смысл текста.

Примеры JSON описывают локальные данные. Имена функций `window.*` — браузерные точки связи, не серверное API. Критерии доступности и приёмки — требования для проверки, не свидетельство её прохождения.
