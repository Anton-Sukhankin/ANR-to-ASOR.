# Карта документации

- `00-project-context.md` - продуктовый контекст и границы первой версии.
- `01-primary-layer.md` - первичный слой проверки ИИ.
- `02-data-model.md` - текущий контракт данных.
- `03-user-flows.md` - пользовательские пути сметчика.
- `04-ui-rules.md` - правила интерфейса таблицы и дровера.
- `05-roadmap.md` - дальнейшие этапы проекта.
- `06-data-foundation.md` - слой данных для масштабирования интерфейса проверки ИИ.
- `07-check-workspace-target.md` - целевая спецификация расширения раздела `Проверка` режимами комплектности, АНР и изменений РД.
