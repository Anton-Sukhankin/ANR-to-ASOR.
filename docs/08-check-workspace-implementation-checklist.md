# Рабочий план и приёмка дровера «Проверка»

Статус: активный. Владелец внутренних требований — [спецификация проверки](07-check-workspace-target.md), общей геометрии и связи панелей — [карта экрана](04-ui-rules.md). Этот файл хранит прогресс и оставшуюся приёмку, не вторую версию UI-контракта.

Отметки реализации унаследованы из завершённых этапов. Они не означают повторную проверку текущего состояния. При содержательной редактуре 11.09.2026 старые размеры и дубли правил удалены из плана; открытая работа не закрыта. [Контрольный срез](../design-qa.md) фиксирует границы проверки.

## Область

Три режима существующего дровера, поток изменений РД и комплектность; АНР проверяется на отсутствие регрессии. Вне области: реальная обработка и хранение, API, роли, изменение основной таблицы, рефакторинг, возврат принятого решения РД и новые функции без решения пользователя.

Первоначальные исключения для редактирования объёма, комментариев РД и фильтрации комплектности отменены последующими прямыми решениями пользователя. Их актуальные границы находятся в спецификации.

## Текущий приёмочный проход

Все пункты ниже открыты для повторного прогона текущей версии; редактура документации не ставит отметок выполнения.

- [ ] Пройти [пути АНР](03-user-flows.md); подтвердить фильтры, сравнение, кандидатов, комментарии и переход к скрытой строке, включая ошибку без строки АСОР.
- [ ] Разобрать [GAP-ANR-01](04-ui-rules.md#table-entry-limits): согласовать отдельную задачу восстановления входа через маркер либо явное изменение требования; не считать наличие данных и функции открытия завершённым пользовательским путём.
- [ ] Пройти UF-03 из спецификации: локальное применение и отмена, следующий активный элемент, счётчики, просмотр результата.
- [ ] Проверить редактор во всех трёх фильтрах РД: Ghost-кнопка, пустой ввод, нормализация, подтверждение, отмена, постоянная высота и отсутствие hover-мерцания. Сохранение объёма не меняет решение.
- [ ] Проверить массовый выбор РД, пустой выбор, отмену режима с восстановлением контекста, подтверждение отмены всех, уведомления и завершение списка.
- [ ] Проверить иерархические похожие строки: существующие цели, исключение дублей, отдельные кнопки ступеней, отсутствие применения при навигации.
- [ ] Пройти UF-02: итог, независимые категории, поиск/фильтры, файл и возврат, свёрнутые логи, комментарий только при допустимом источнике, демонстрационное скачивание и пересчёт.
- [ ] Разобрать GAP-CMP-01 и GAP-CMP-02 из § 12 спецификации: исправить по отдельной задаче либо получить явное решение об изменении требования; не закрывать как выполненные сейчас.
- [ ] Проверить смену вкладок и компоновки: сохранение решений, установленный сброс комплектности, незавершённый ввод, ограничение массового режима.
- [ ] Проверить 1440×900 и уменьшенное desktop-окно по [общей геометрии](04-ui-rules.md#screen-geometry), включая обе стороны порога двух колонок, отсутствие непредусмотренного перекрытия и скачков; проверить reduced motion.
- [ ] Пройти [межпанельный путь](04-ui-rules.md#host-interactions): проверка → чат → закрытие → проверка → перезагрузка; сопоставить видимость, контекст и срок жизни состояния с контрактом, не ожидать автоматической передачи выбранной проблемы или постоянной истории чата.
- [ ] Пройти клавиатурный обход, видимый фокус, доступные имена и возврат фокуса; цвет не является единственным носителем смысла.

## Закрытие

План закрывается после подтверждения открытых этапов 5 и 10, обработки известных расхождений и записи свежего результата проверки. Перенос работы допустим только в другой действующий план с явным решением пользователя. Удаление старой документации или наличие реализации не являются основанием закрытия.
